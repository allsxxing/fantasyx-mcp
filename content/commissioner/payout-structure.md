# Payout Structure

- **Format:** Winner take all (additional side pots possible via league vote).
- **Base buy-in:** $10 (1X).
- **❌ multiplier** scales the buy-in and therefore the winner's bag:
  - 1X → $10
  - 2.5X → $25
  - 5X → $50
  - 10X → $100
  - OTHER → league-defined
- **Multiplier status:** pending the ❌ Vote poll (see `dues.json`).
- **Payment method:** LeagueSafe.

> Paid/unpaid status, payment handles, and contacts are **private** — served only via the
> admin endpoint from `FANTASYX_PRIVATE_DATA`, never committed. LeagueSafe join link: see
> `links.json`.
